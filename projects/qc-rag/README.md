# QC-RAG · 面向配方专利的量化证据检索

配方问题常要求同时说清调整了什么、指标变化多少、与什么条件比较，以及结论来自哪份专利。QC-RAG 将结构化的实验与配方证据用于检索，再由回答模型组织引用与结论。

## 系统架构

~~~mermaid
flowchart LR
    P["配方专利文档"] --> X["结构化抽取与入库"]
    X --> G["Neo4j 证据图"]
    U["用户问题"] --> I["意图解析与检索计划"]
    I --> M["量化证据、同专利对比、跨专利支持"]
    G --> M
    M --> S["候选选择与证据上下文"]
    S --> A["生成带证据引用的回答"]
~~~

- **量化证据**检索配方变更、性能指标、数值和相关条件，支持回答“变化多少”。
- **同专利对比**优先检索同一专利内的实施例与对照线索。
- **跨专利支持**整理共享机制的支持记录，帮助回答“哪些来源出现了类似趋势”。

我的工作涵盖知识抽取流程、图谱检索开发、基线对照和错例复盘。

## 评测摘录

归档研究实验使用 QC-RAG **V3**，四种方法使用同一组 120 个问题。以下为该组实验的平均评分。

| 方法 | Overall | 量化深度 |
| --- | ---: | ---: |
| 仅大模型 | 4.556 | 4.217 |
| 向量 RAG | 4.436 | 2.892 |
| 通用图谱 RAG | 5.625 | 4.592 |
| QC-RAG | **6.447** | **6.217** |

该组中，QC-RAG 的 Overall 相对通用图谱 RAG 高约 **14.6%**。这是综合评分的相对变化。研究发布包里的 **V4** 是后续实现，表中数值归属 V3。配方相似、实验条件缺失或来源矛盾时，结果需要结合原文核查。
